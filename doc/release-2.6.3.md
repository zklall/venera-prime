# Venera Prime 2.6.3

这是 `zklall/venera-prime` 的 fork 版本，基于上游 2.6.3。本次仅发布 Android ARM64 APK，适用于 vivo X Fold6。

## 本次更新

- **内置更新使用自己的仓库**：启动检查、手动检查更新、安装包下载校验和关于页 GitHub 链接统一使用 `zklall/venera-prime`。没有已发布的 Release 时显示“没有新版本”；后续从本仓库的稳定 Release 检测新版并选择 ARM64 APK。
- **双页漫画排版**：双页模式默认首张封面单独显示，后续按第 2–3、4–5 页依次配对，修复 Komiic《黄金神威》第二卷第 46–47 张图片被分到相邻两组的问题；可在阅读设置调整首张单独显示。两页按相同高度和各自比例共同适配阅读区域；横向宽图可独占跨页，支持手动调整跨页配对和双击放大单页。
- **章节名称排序**：纯数字、中文和英文格式的章名按卷号、话号混合排序，例如 `第1话 → 2 → Chapter 3 → 第10话`；源默认排序保持漫画源返回的顺序。
- **红色图标和独立安装**：桌面名称为 `Venera Prime Fork`，包名为 `com.github.zklall.venera.prime`，可与原版同时安装，数据各自独立。

## 请更新后验证并反馈

请安装 2.6.3，复查双页阅读、章节名称排序和更新检查；关联 issue 的提出者也请按原来的复现步骤复查。

- 问题已解决时，请在原 issue 中确认，并及时关闭尚未关闭的 issue。
- 问题仍存在时，请提供版本号、系统与设备、漫画源、复现步骤及必要的日志或录屏；已关闭的问题也可继续留言或重新打开。
- 日志、截图和录屏请遮盖账号、密码、令牌及 WebDAV 私有地址等敏感信息。
- 构建和自动化测试通过不代表所有设备、漫画源或服务端已验证，也不会自动关闭 issue。
